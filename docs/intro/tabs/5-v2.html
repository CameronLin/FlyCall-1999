我先說明一下，攀爬架一個扶手接點鬆脫，拉一下就能感覺它左右移動，位置大概在大安區一般公園的活動空間附近。

可以再說一點當時看到或感覺到的情形嗎？

我回想一下，先注意到攀爬架一個扶手接點鬆脫，拉一下就能感覺它左右移動。

嗯，我聽到了。你記得最早什麼時候發現，後來有沒有再遇到？

最早大概最近幾個傍晚就有一點，只是當時沒停下來看，最近才確認不是偶然。

謝謝你說明。你怎麼確認這個狀況一直在同一處？

回頭再看時，我在旁邊看見固定螺栓附近有空隙，設備使用時會晃。

謝謝你的說明，我會照你提供的觀察內容記錄，不另外替現場推測原因。

v2TPE1999-V2-PK-0101

您好，1999專線，請說明您的狀況。

你好，我帶小孩去公園玩，那個盪鞦韆的鐵鍊有一邊快斷了，有一個環扣被磨得很細，小朋友盪的時候會發出喀喀的聲音，我很怕它突然斷掉，小孩會整個摔出去。

嗯，方便說一下地點嗎？

大安區，靠近捷運科技大樓站的一個社區公園，兒童遊戲區最裡面那組鞦韆。

那組鞦韆有幾個座位？是哪一個座位有問題？

有兩個座位，左邊那個的右側鐵鍊，靠近上面橫桿的地方，有一個環被磨到剩一半粗。

座椅本身有沒有破損？

座椅還好，就是那條鍊子。現在還有很多小朋友排隊在盪，家長都不知道。

好，科技大樓站附近社區公園遊戲區內側鞦韆，左座右側鐵鍊近橫桿處一環磨損至約半粗，擺盪時有異音，座椅正常，仍有兒童使用，已經寫進紀錄。

嗯，拜託了。

不客氣，也麻煩您先提醒在場的家長。

位置大約是內湖區一般道路路段，我想反映的是這個狀況：慢車道輪跡處比兩側低，表面像被壓出一條連續的凹帶。

你實際通過或使用時，最明顯受到什麼影響？

最明顯就是騎機車時車身會左右晃一下，載東西更難保持穩定。

了解，我再順著剛才那點問。你最近幾次經過時看到的狀況都相同嗎？

前幾次看到的都差不多，我從路邊看到低槽大致跟著車輪線走，不是橫向接縫造成的一下震動。

我從路邊看到低槽大致跟著車輪線走，不是橫向接縫造成的一下震動。

我知道了。你大概從什麼時候開始注意到，最近遇到幾次？

我大約在上週後段第一次留意，後來隔幾天又遇到；今天再看仍是同一種情形。

了解，前後經過我都記下了，今天先謝謝你來電說明。

請問是哪一條路呢？

萬華區，西園路二段、往華中橋彼个方向，內側車道。

真長喔，差不多兩百公尺，攏仝一个位，就是輪仔硩的所在。

無破，干焦凹，柏油猶閣好好。

了解，西園路二段、往華中橋內側車道，沿輪跡兩條約兩百公尺的縱向凹槽，深兩公分以上，雨天積水，行駛時方向盤會被帶。

著，就是按呢，拜託喔。

好，多謝您，這邊攏有記起來矣。

讀 test 前，先用 validation 鎖定 51 個候選與選模規則，並確認從存檔重新計算的 validation 完全一致；每個候選只評估一次。

解釋
  • 去掉捷徑後，模型不能再靠背句型；validation 整體略升，但 test 顯示有些情境家族明顯比較難（E5 → LR 掉了 0.16）。

  • 依規則選定的果蠅模型與簡單的 LDA 方法大致同一水準，還沒有穩定勝出。
