04　程式如何串接

Fly A 產生表示，Fly B 輸出分類 logits

Fly A.forwardgraph_core.py · 262–268
# E5 嵌入 → 正規化 32 維表示
normalized = embeddings / norm
drives = torch.tanh(
    self.input_projection(normalized)
)
output = self.graph_core(drives)
output_norm = torch.linalg.vector_norm(
    output, ord=2, dim=1, keepdim=True
)
return output / output_norm

把 E5 嵌入投影到 32 維，送入圖核心，再正規化輸出。

Fly B.forwardgraph_core.py · 320–322
# Fly A 的輸出必須是 32 維
if fly_a_output.ndim != 2 or fly_a_output.shape[1] != 32:
    raise GraphCoreError("fly_a_output must have shape (batch, 32)")
drives = self.input_adapter(
    fly_a_output
)
graph_output = self.graph_core(drives)
return self.readout(graph_output)

Fly B 經圖核心後，用 readout 產生五類 logits。

原始碼節錄；略去 norm 計算、輸入型別與有限值檢查。推論階段會確認 E5 輸出為 384 維。
